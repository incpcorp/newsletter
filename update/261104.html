EU GMP 4장 개정 초안 — 어떤 데이터가 기초 자료인지 정해 두세요

최종안 제출 목표가 2026년 4분기입니다. 초안은 품질 결정에 쓴 데이터는 모두 기초 자료로 정의하라고 합니다

2026. 11. 4(수)규제 동향AI 초안 Claude · 검토 김정민

유럽 GMP 4장(문서화) 개정 초안은 2025년 7월 7일부터 10월 7일까지 공개 협의를 거쳤고, EMA GMDP 실사관 작업반의 2026~2028 업무계획은 4장·Annex 11·Annex 22의 최종안을 유럽집행위원회에 넘기는 목표 시점을 "Target date Q4 2026"으로 적었습니다. 2026-11-03 기준 EudraLex Vol.4 페이지에는 아직 2011년판이 올라 있으므로, 아래 내용은 모두 초안 기준입니다.

초안은 문서화의 출발점을 데이터 관리체계(data governance)로 옮깁니다. #4.10은 종이·전자·하이브리드를 가리지 않고 "a data governance system integral to the pharmaceutical quality system"을 두라고 하고, #4.13은 통제 수준을 데이터 중요도와 데이터 위험으로 정하되, 데이터 위험에 "likelihood of detection / visibility of changes by the regulated user's routine review processes"를 포함합니다. 변경이 일어날 수 있는지만이 아니라, 우리 검토 절차가 그 변경을 볼 수 있는지가 위험의 일부라는 뜻입니다.

기록(Record)의 정의도 달라집니다. #4.27(iv)는 전자기록에서 어떤 데이터를 기초 자료(Raw Data)로 볼지 규제 대상자가 정의하도록 하고, "At least, all data on which quality decisions are based should be defined as raw data"라고 못 박습니다. #4.26은 전자 데이터를 종이로 바꿔 보관하는 것을 하이브리드 시스템 요건을 충족하거나 변환의 정확성을 검증·확인한 경우로 한정합니다. #4.43은 출하 결정 시점에 모든 기록을 QP가 볼 수 있어야 하고, 중요 데이터의 변경을 표시하는 체계를 요구합니다.

오늘 확인할 것

  • 시스템별로 "무엇이 기초 자료인가"가 문서로 정의되어 있는지 — 출력물만 남기고 전자 원본을 지우는 운영은 #4.26·#4.27(iv) 기준으로 다시 봐야 합니다.
  • 데이터 위험평가 항목에 "변경을 우리 검토 절차가 발견할 수 있는가"(#4.13)가 들어 있는지 — 점검기록(감사추적) 검토 범위와 바로 이어집니다.
  • 남은 위험을 정기적으로 검토해 경영진에게 알리는 통로(#4.17)가 품질시스템 안에 있는지.

데이터 관리체계는 문서 한 권이 아니라, 변경이 보이게 만드는 체계입니다.
